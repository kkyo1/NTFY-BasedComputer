# NTFY-BasedComputer
Integrations between computer, mobile phone, and Python


*Como automatizar a abertura de aplicativos em um computador utilizando Python?*

Imagine uma pequena empresa que possui uma estação de trabalho dedicada a determinadas tarefas. Sempre que alguém precisa iniciar um aplicativo, é necessário acessar o computador manualmente.

Pensando nesse tipo de situação, desenvolvi um projeto pessoal para explorar como essa tarefa poderia ser automatizada.

💡 A solução

Utilizei Python e o serviço ntfy para criar um mecanismo que recebe notificações, interpreta comandos predefinidos e abre aplicativos específicos no Windows.

🛠️ Tecnologias utilizadas
- Python
- Requests para requisições HTTP
- JSON para processamento de mensagens
- Subprocess para execução de aplicativos
- Logging para registro de eventos e erros
- Pathlib para manipulação de arquivos e diretórios

📌 O que esse projeto me permitiu praticar?

Além de implementar a automação, trabalhei com tratamento de exceções, organização do código em funções e separação de responsabilidades.

O próximo passo é continuar aprimorando a validação das mensagens e a confiabilidade do processo.

Esse é um projeto pessoal de aprendizado, desenvolvido para explorar possibilidades de automação de tarefas operacionais.
